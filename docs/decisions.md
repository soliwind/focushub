# 확정된 결정 사항 (2026-10-16)

## 범위

- 대학교 과제용 MVP다. 실제 운영 수준의 확장성보다 시연 안정성을 우선한다.
- 1차 구현: 계정 인증(6.1), 타이머(1.1), 탭 이탈 감지(2.2), 이탈 알림 설정(7.1), 장기 이탈 처리(7.2), 기록 조회(3.1), 통계(3.2), 그룹 생성·참여·관리(4.3), 그룹 집계(4.4)
- 2차 구현(시간이 남으면): 복귀 루틴(2.1), 조용한 동행방(4.2), 습관 챌린지(4.1)
- 랜딩 페이지(2026-10-16 추가): 로그인하지 않은 사용자에게 서비스 소개와 로그인·회원가입 버튼을 보여준다. 3단계에서 로그인과 함께 만든다.
- 수동 운영으로 대체: 계정·기록 삭제 요청(6.2)은 요청 접수 화면만 만들고 처리는 관리자가 직접 한다.

## 타이머 규칙 변경 (2026-10-16, 2단계 구현 후)

PRD와 기능명세서의 탭 이탈 관련 내용(이탈 횟수·이탈 시간 집계, 장기 이탈 확인)보다 이 결정이 우선한다.

1. 타이머 상태는 **공부 중**과 **일시정지** 두 가지뿐이다. 버튼은 "일시정지"와 "마치고 저장"(정지)만 있다.
2. 다른 탭으로 가면(`visibilitychange`로 탭이 가려지면) **즉시 일시정지**한다. 돌아와도 자동으로 재개하지 않는다.
3. 탭 이탈로 생긴 일시정지와 직접 누른 일시정지는 같은 것으로 취급하고 기록에서도 구분하지 않는다.
4. 일시정지 시간은 학습 시간에서 뺀다. 이탈 시간을 학습 시간에 포함하던 규칙은 없어졌다.
5. 일시정지 횟수·시간은 사용자에게 보여주지 않는다. 언제 몇 분 쉬었는지는 세션 events에 데이터로만 남기고, 나중에 공부 타임라인을 만들 때 쓴다.
6. 일시정지 중에는 복귀 루틴(2.1)을 보여준다. 이어서 할 일을 한 줄 적고 "다시 시작"하거나 "마치고 저장"할 수 있다.
   - 탭을 떠났다 돌아온 경우: "다시 왔네요. ○분 동안 자리를 비웠어요."
   - 직접 일시정지한 경우: "잠시 쉬는 중이에요."
7. 일시정지가 기준 시간(사용자 설정 10~120분, 기본 30분)을 넘으면 묻지 않고 **쉬기 전까지로 자동 저장**한다. 끝난 시각은 기준을 넘긴 순간으로 기록한다. "계속 공부하고 있었어요" 선택지는 없다.
8. "탭을 떠나면 알림" 설정(7.1)은 탭을 떠나 일시정지됐을 때 브라우저 탭 제목을 "일시정지 · 공부 내용"으로 바꿀지만 정한다. 일시정지 자체는 설정과 상관없이 항상 일어난다.

## 기술

- 백엔드는 Firebase(Authentication + Firestore)를 사용한다. 개발 경험이 적은 사람이 콘솔에서 데이터를 눈으로 확인하며 작업하기 쉽기 때문이다.
- 탭을 닫아 버린 세션은 다음 접속 때 마지막 heartbeat 시각을 기준으로 정리한다(서버 예약 작업은 쓰지 않는다). 신호가 2분 넘게 끊겼으면 마지막 신호 시각에 일시정지한 것으로 보고, 위 7번 자동 저장 규칙을 똑같이 적용한다. 공부 중 컴퓨터가 잠들었다 깨어난 경우도 같다.
- 새로고침은 탭 이탈로 세지 않는다. 브라우저는 새로고침할 때도 탭이 가려졌다고 알려 주므로 `pagehide` 이벤트로 구분한다. 2분 안에 다시 열면 공부 중인 채로 이어진다.
- 타이머 세션은 화면이 아니라 앱 전체(`TimerSessionProvider`)에서 관리한다. 기록·그룹 메뉴를 보는 동안에도 타이머가 이어진다.
- 진행 중인 세션을 시작할 때 Firestore에서 내 열린 세션을 찾아, 있으면 새로 만들지 않고 그 세션을 이어서 보여 준다.
- 개발 모드(2026-10-16 추가): `.env.local` 없이 `npm run dev`를 실행하면 Firebase 대신 "개발용 사용자"로 로그인된 상태가 되고, 기록 화면은 예시 데이터(`src/lib/sampleData.ts`)를 보여준다. 배포용 빌드에서는 동작하지 않는다. Firebase 계정을 쓸 수 있게 되면 `.env.local`만 만들면 실제 Firebase로 바뀐다.

## 스터디그룹 결정 (2026-10-31, 6단계 구현 중)

1. 그룹 운영자는 탈퇴할 수 없다. 운영자가 없으면 가입 요청을 처리할 사람이 없기 때문이다.
2. 초대 링크는 `/join/그룹ID?code=초대코드` 형식이고 만료되지 않는다. 코드가 맞아야 가입하거나 요청할 수 있다.
3. 저장을 마친 세션의 공유 여부는 바꿀 수 없다. 저장 화면에서는 "그룹에 기록 공유"를 잠근다.
4. 가입 전에 마친 세션은 그룹에 더하지 않는다. 탈퇴한 사람의 지난 시간은 그룹 합계에 남지만 구성원 목록에서는 빠진다.
5. 공동 목표는 그룹을 만들 때 정한다. 지금은 나중에 바꾸는 화면이 없다.

## 시연 준비 메모

- 광고 차단·개인정보 보호 확장 프로그램이나 브라우저 차단 기능이 Firebase 로그인 요청(`identitytoolkit.googleapis.com`)을 막으면 "인터넷 연결을 확인해 주세요."가 뜬다. 시연할 브라우저에서는 이런 기능을 끄거나 시크릿 창을 쓴다. (2026-10-31 개발 중 실제로 겪음)
