# 구현 순서와 Claude Code에 보낼 요청

한 단계가 끝나면 브라우저에서 직접 확인하고, 잘 되면 커밋한 뒤 다음 단계로 넘어간다.
각 단계의 요청 문장은 그대로 복사해서 써도 된다.

## 0단계. 준비
> CLAUDE.md와 docs 폴더를 읽고, 이 프로젝트를 어떤 순서로 만들지 내 수준에 맞게 짧게 설명해줘. 아직 코드는 고치지 마.

기존 React 프로토타입이 있다면 그 폴더에 `CLAUDE.md`와 `docs`를 넣고 시작한다. 없다면:
> Vite로 React + TypeScript 프로젝트를 만들고, docs/design.md의 색 토큰과 글꼴을 적용한 빈 화면 세 개(타이머, 기록, 스터디그룹)와 상단 메뉴를 만들어줘.

## 1단계. 화면 뼈대 (데이터 없이)
> docs/design-reference/timer.html을 참고해서 타이머 화면을 React로 옮겨줘. 아직 저장은 하지 말고, 시작·일시정지·재개·종료가 화면에서만 동작하게 해줘. 타이머는 시각을 저장해서 계산하는 방식으로 만들어줘.

## 2단계. 탭 이탈 감지
> visibilitychange로 탭 이탈을 감지해서 이탈 횟수와 시간을 기록하고, 탭 제목을 상태에 맞게 바꿔줘. 돌아오면 복귀 안내를 보여주고, 설정한 장기 이탈 기준을 넘었으면 이탈 전까지만 기록할지 물어보게 해줘.

## 3단계. Firebase 연결과 로그인
> Firebase 프로젝트를 연결하는 방법을 단계별로 알려줘. 그다음 이메일 회원가입·로그인·로그아웃 화면을 만들어줘.

(이 단계에서 Firebase 콘솔 작업은 직접 해야 한다. Claude Code가 알려주는 순서를 따라가면 된다.)

## 4단계. 세션 저장과 복구
> docs/data-model.md대로 세션을 Firestore에 저장해줘. 시작하면 active로 저장하고, 새로고침해도 진행 중인 세션이 복구되게 해줘. 진행 중인 세션은 하나만 허용해줘.

## 5단계. 기록과 통계 화면
> docs/design-reference/records.html을 참고해서 기록 화면을 만들어줘. 하루는 오전 5시 기준이고, 이번 주 문장 요약, 요일별 막대, 날짜별 세션 목록, 최근 12주 히트맵을 보여줘.

## 6단계. 스터디그룹
> 그룹 만들기, 초대 링크로 가입, 승인제 가입 요청과 운영자 승인·거절, 탈퇴를 만들어줘.

> 세션을 저장할 때 내가 가입한 모든 그룹에 contributions를 더하고, docs/design-reference/group.html을 참고해서 그룹 화면을 만들어줘. 순위는 매기지 말고 이름순으로 보여줘.

## 7단계. 보안 규칙과 배포
> Firestore 보안 규칙을 만들어줘. 내 세션은 나만 쓰고 읽을 수 있고, 그룹 데이터는 그 그룹 구성원만 읽을 수 있게 해줘. 그다음 배포 방법을 알려줘.

## 8단계. 시간이 남으면
- 조용한 동행방 (Firestore 실시간 구독으로 "지금 공부 중" 표시)
- 습관 챌린지
- 삭제 요청 접수 화면
