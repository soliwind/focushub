# 디자인 규칙

확정 시안: `docs/design-reference/timer.html`, `records.html`, `group.html`
(랜딩 페이지와 로그인·회원가입 화면은 시안이 없다. 이 문서의 규칙을 따라 만든다.)

## 핵심 아이디어

- **화면의 배경색이 지금 상태를 알려준다.** 아이콘이나 경고 문구를 늘리지 않는다.
- **하늘색(#ECF8F8)은 "지금 공부 중"과 "오늘·진행 중인 것"을 가리키는 포인트다.** 단독 면으로 쓰지 않고, 항상 따뜻한 색으로 이어지는 그라데이션의 끝부분에만 쓴다. (진행 바, 오늘 막대, 오늘 점, 랜딩 구분선. 토큰 `--dawn-*`) 새벽 하늘이 땅의 색으로 바뀌는 모습이며, 하루가 오전 5시에 시작된다는 규칙과 연결된다.
- 순위와 경쟁 대신 꾸준함을 보여준다.

## 글꼴

- 본문: IBM Plex Sans KR (400, 500, 600)
- 타이머 숫자만: Red Hat Mono 300
- 다른 숫자는 본문 글꼴에 `font-variant-numeric: tabular-nums`만 적용한다.
- Inter, Roboto, Pretendard 기본 조합은 쓰지 않는다.

## 레이아웃

- 카드를 남발하지 않는다. 영역은 여백과 1px 구분선(`--line`)으로 나눈다.
- 상자(배경이 있는 영역)는 흐름을 끊고 들어오는 안내(일시정지 중 복귀 안내)와 동행방에만 쓴다.
- 모서리는 두 가지만: 큰 영역 16px, 버튼·입력창·막대 10px.
- 메뉴는 알약 모양 탭이 아니라 밑줄 텍스트 링크로 한다.
- 그림자, 이모지, 보라·파랑 그라데이션을 쓰지 않는다.
- 페이지 좌우 여백 56px, 최대 너비 1280px.

## 스마트폰 화면

- 규칙은 `src/styles/responsive.css` 한 파일에 모은다. 기준은 너비 720px이고 PC 화면에는 영향을 주지 않는다.
- 좌우 여백은 20px, 버튼·입력칸의 누르는 높이는 44px 이상, 입력칸 글자는 16px 이상으로 한다.
- 두 칸 배치는 한 칸으로 쌓고, 타이머 숫자는 화면 너비에 맞춰 줄인다.

## 화면별 핵심

- **타이머:** 화면 전체 배경이 상태에 따라 바뀐다(공부 중 그라데이션, 일시정지 모래색). 상태 표시(점 + 단어) → 공부 내용 입력 → 큰 타이머 숫자(148px) → 버튼. 오른쪽에 이번 세션 기록, 아래쪽에 설정 한 줄.
  - 공부 중: "마치고 저장", "일시정지" 버튼.
  - 일시정지 중: 버튼 대신 복귀 안내 상자. 이어서 할 일 입력칸, "다시 시작", "마치고 저장", 자동 저장 기준 한 줄.
  - 시안(timer.html)의 자리 비움 화면, 이탈 요약 줄, "시연" 버튼, 장시간 자리 비움 선택지("계속 공부하고 있었어요")는 쓰지 않는다.
- **기록:** 시안(records.html)의 "자리 비움 N번" 표시는 쓰지 않는다. 일시정지 횟수·시간도 보여주지 않는다. 숫자 카드 대신 문장으로 시작한다. "이번 주에는 5일 동안 16시간 40분 공부했어요." 그 아래 요일별 막대, 날짜별 세션 목록, 최근 12주 히트맵.
- **그룹:** 공동 목표 문장과 굵은 막대가 중심이다. 구성원은 이름순, 요일별 점으로 공부한 날을 표시한다. 시안(group.html)의 동행방, 챌린지, "지금 공부 중" 표시는 2차 구현 전까지 넣지 않는다.
- **랜딩:** 로그인하지 않은 사용자가 처음 보는 소개 화면이다. 한 문장 소개 → 로그인·회원가입 버튼 → 핵심 특징 몇 줄(다른 탭으로 가면 자동으로 일시정지하고 다른 탭 내용은 보지 않음, 그룹에 자동 합산, 순위 없이 꾸준함). 카드 나열 대신 여백과 구분선으로 나눈다. 내용은 PRD에서 가져오고, 없는 수치나 후기를 지어내지 않는다.

## 문구

- 버튼과 라벨은 짧고 건조하게: "마치고 저장", "일시정지", "다시 시작"
- 감정이 오가는 순간(복귀, 저장 완료)에만 다정한 문장을 쓴다: "다시 왔네요. 4분 동안 자리를 비웠어요."
- "이탈이 감지되었습니다", "성공적으로", 느낌표를 쓰지 않는다.
- "다른 탭으로 가면 일시정지하고, 다른 탭의 내용은 보지 않는다"는 설명은 화면마다 한 곳에만 둔다.
- 명세에 없는 수치(목표 시간, 지난주 대비 증감 등)를 만들어 넣지 않는다.
