# 디자인 규칙

확정 시안: `docs/design-reference/timer.html`, `records.html`, `group.html`
(랜딩 페이지와 로그인·회원가입 화면은 시안이 없다. 이 문서의 규칙을 따라 만든다.)

## 핵심 아이디어

- **화면의 배경색이 지금 상태를 알려준다.** 아이콘이나 경고 문구를 늘리지 않는다.
- **파란색은 포인트 색이다.** 타이머 시작(시작 버튼, 공부 중 표시)과 그래프(진행 바, 오늘 막대, 오늘의 띠, 오늘 점, 학습 달력)에만 단색으로 쓴다. 토큰은 `--point`, `--point-deep`. 가장 옅은 `--sky`는 공부 중 배경 윗부분과 내 구성원 상자에 쓴다. 새벽 하늘이 땅의 색으로 바뀌는 모습이며, 하루가 오전 5시에 시작된다는 규칙과 연결된다.
- 순위와 경쟁 대신 꾸준함을 보여준다.

## 색 토큰 (`src/styles/tokens.css`)

```css
:root {
  /* 팔레트 원색: https://coolors.co/palette/ecf8f8-eee4e1-e7d8c9-e6beae-b2967d */
  --sky: #ECF8F8;        /* 지금 공부 중, 오늘·진행 중 (그라데이션 끝부분에서만) */
  --blush: #EEE4E1;
  --sand: #E7D8C9;       /* 일시정지 */
  --peach: #E6BEAE;      /* 자리 비움 */
  --taupe: #B2967D;      /* 공부한 시간. 단색 강조는 이 색만 쓴다 */

  /* 바탕과 글자 */
  --page: #F2ECE7;
  --ink: #3A2F28;
  --ink-2: #6E5E52;
  --line: rgba(58, 47, 40, 0.18);
  --line-soft: rgba(58, 47, 40, 0.08);

  /* 버튼 (흰 글자 대비 확보용) */
  --primary: #7A6250;

  /* 상태 글자색 */
  --live-ink: #4F6B66;   /* 공부 중 글자, 하늘색과 베이지를 잇는 회청록 */
  --live-dot: #7FA39C;
  --away-ink: #7A4433;
  --away-dot: #C98E78;

  /* 상태별 배경 */
  --bg-focus: linear-gradient(180deg, #ECF8F8 0%, #EEF1EC 38%, #EEE4E1 72%, #E9DCCF 100%);
  --bg-away: linear-gradient(180deg, #F1E7E2 0%, #EBD3C8 100%);
  --bg-paused: #EBE1D7;
  --bg-idle: #F2ECE7;

  /* 학습 달력 농도: 갈색 → 하늘색이 섞인 갈색 → 하늘색 → 진한 하늘색 */
  --heat-0: #E6DDD5; --heat-1: #C9B39F; --heat-2: #B4BDAF; --heat-3: #9FD3D8; --heat-4: #5FB0BD;

  --point: #8FD0D6;
  --point-deep: #5FB0BD;

  --radius-control: 10px;
```

타이머 규칙 변경(`decisions.md`)으로 "자리 비움" 상태가 없어져 `--peach`, `--away-ink`, `--away-dot`, `--bg-away`는 지금 쓰지 않는다. 나중을 위해 토큰은 남겨 둔다.

## 글꼴

- 본문: IBM Plex Sans KR (400, 500, 600)
- 타이머 숫자만: Red Hat Mono 300
- 다른 숫자는 본문 글꼴에 `font-variant-numeric: tabular-nums`만 적용한다.
- Inter, Roboto, Pretendard 기본 조합은 쓰지 않는다.

## 레이아웃

- 카드를 남발하지 않는다. 영역은 여백과 1px 구분선(`--line`)으로 나눈다.
- 상자(배경이 있는 영역)는 흐름을 끊고 들어오는 안내(일시정지 중 복귀 안내), 스터디그룹 방 목록, 구성원 상자에만 쓴다.
- 모서리는 두 가지만: 큰 영역 16px, 버튼·입력창·막대 10px.
- 메뉴는 알약 모양 탭이 아니라 밑줄 텍스트 링크로 한다.
- 그림자, 이모지, 보라·파랑 그라데이션을 쓰지 않는다.
- 페이지 좌우 여백 56px, 최대 너비 1280px.

## 스마트폰 화면

- 규칙은 `src/styles/responsive.css` 한 파일에 모은다. 기준은 너비 720px이고 PC 화면에는 영향을 주지 않는다.
- 좌우 여백은 20px, 버튼·입력칸의 누르는 높이는 44px 이상, 입력칸 글자는 16px 이상으로 한다.
- 두 칸 배치는 한 칸으로 쌓고, 타이머 숫자는 화면 너비에 맞춰 줄인다.

## 화면별 핵심

- **타이머:** 화면 전체 배경이 상태에 따라 바뀐다(공부 중 그라데이션, 일시정지 모래색). 상태 표시(점 + 단어) → 공부 내용 입력 → 큰 타이머 숫자(148px) → 버튼. 오른쪽에 이번 세션 기록, 아래쪽에 설정 한 줄.
  - 시작 전: 오른쪽에 오늘 공부 시간, 연속 일수, 지난번 이어서 할 일, 최근 공부(누르면 바로 시작). 아래쪽에 오전 5시부터 다음 날 5시까지의 "오늘의 띠". 띠는 저장 화면에도 보인다.
  - 공부 중: "마치고 저장", "일시정지" 버튼.
  - 일시정지 중: 버튼 대신 복귀 안내 상자. 이어서 할 일 입력칸, "다시 시작", "마치고 저장", 자동 저장 기준 한 줄.
  - 시안(timer.html)의 자리 비움 화면, 이탈 요약 줄, "시연" 버튼, 장시간 자리 비움 선택지("계속 공부하고 있었어요")는 쓰지 않는다.
- **기록:** 시안(records.html)의 "자리 비움 N번" 표시는 쓰지 않는다. 일시정지 횟수·시간도 보여주지 않는다. 숫자 카드 대신 문장으로 시작한다. "이번 주에는 5일 동안 16시간 40분 공부했어요." 그 아래 요일별 막대, 날짜별 세션 목록, 학습 달력(한 달 달력에 공부 시간 농도). 이번 주는 `‹ ›`로 이전 주를 볼 수 있다. 지난주와 비교하는 수치는 넣지 않는다.
- **그룹:** 스터디그룹 메뉴는 내 방 목록(상자)부터 보여 준다. 방에 들어가면 맨 위에 공동 목표 게이지, 그 아래 구성원 상자가 이름순으로 나온다. 상자에는 사진, 이름, 오늘 공부 시간(32px), 요일별 점이 있고, 내 상자만 `--sky` 단색으로 옅게 표시한다. 스마트폰에서는 오늘 공부 시간을 이름 옆에 두어 세로 길이를 줄인다. 초대 링크는 작은 글자 링크로 둔다. 상자를 누르면 소개 메시지, 총 공부 시간, 학습 달력을 보여 주는 구성원 화면으로 간다. 시안(group.html)의 동행방, 챌린지, "지금 공부 중" 표시는 2차 구현 전까지 넣지 않는다.
- **랜딩:** 로그인하지 않은 사용자가 처음 보는 소개 화면이다. 한 문장 소개 → 로그인·회원가입 버튼 → 핵심 특징 몇 줄(다른 탭으로 가면 자동으로 일시정지하고 다른 탭 내용은 보지 않음, 그룹에 자동 합산, 순위 없이 꾸준함). 카드 나열 대신 여백과 구분선으로 나눈다. 내용은 PRD에서 가져오고, 없는 수치나 후기를 지어내지 않는다.

## 문구

- 버튼과 라벨은 짧고 건조하게: "마치고 저장", "일시정지", "다시 시작"
- 감정이 오가는 순간(복귀, 저장 완료)에만 다정한 문장을 쓴다: "다시 왔네요. 4분 동안 자리를 비웠어요."
- "이탈이 감지되었습니다", "성공적으로", 느낌표를 쓰지 않는다.
- "다른 탭으로 가면 일시정지하고, 다른 탭의 내용은 보지 않는다"는 설명은 화면마다 한 곳에만 둔다.
- 명세에 없는 수치(목표 시간, 지난주 대비 증감 등)를 만들어 넣지 않는다.
