# 디자인 규칙

확정 시안: `docs/design-reference/timer.html`, `records.html`, `group.html`

## 핵심 아이디어

- **화면의 배경색이 지금 상태를 알려준다.** 아이콘이나 경고 문구를 늘리지 않는다.
- **하늘색(#ECF8F8)은 "지금 공부 중"이라는 뜻 하나만 가진다.** 단독 면으로 쓰지 않고, 항상 따뜻한 색으로 이어지는 그라데이션의 윗부분에만 쓴다. 새벽 하늘이 땅의 색으로 바뀌는 모습이며, 하루가 오전 5시에 시작된다는 규칙과 연결된다.
- 순위와 경쟁 대신 꾸준함을 보여준다.

## 글꼴

- 본문: IBM Plex Sans KR (400, 500, 600)
- 타이머 숫자만: Red Hat Mono 300
- 다른 숫자는 본문 글꼴에 `font-variant-numeric: tabular-nums`만 적용한다.
- Inter, Roboto, Pretendard 기본 조합은 쓰지 않는다.

## 레이아웃

- 카드를 남발하지 않는다. 영역은 여백과 1px 구분선(`--line`)으로 나눈다.
- 상자(배경이 있는 영역)는 흐름을 끊고 들어오는 안내(복귀, 장시간 자리 비움)와 동행방에만 쓴다.
- 모서리는 두 가지만: 큰 영역 16px, 버튼·입력창·막대 10px.
- 메뉴는 알약 모양 탭이 아니라 밑줄 텍스트 링크로 한다.
- 그림자, 이모지, 보라·파랑 그라데이션을 쓰지 않는다.
- 페이지 좌우 여백 56px, 최대 너비 1280px.

## 화면별 핵심

- **타이머:** 화면 전체 배경이 상태에 따라 바뀐다. 상태 표시(점 + 단어) → 공부 내용 입력 → 큰 타이머 숫자(148px) → 이탈 요약 → 버튼. 오른쪽에 이번 세션 기록, 아래쪽에 설정 한 줄.
- **기록:** 숫자 카드 대신 문장으로 시작한다. "이번 주에는 5일 동안 16시간 40분 공부했어요." 그 아래 요일별 막대, 날짜별 세션 목록, 최근 12주 히트맵.
- **그룹:** 공동 목표 문장과 굵은 막대가 중심이다. 구성원은 이름순, 요일별 점으로 공부한 날을 표시한다.

## 문구

- 버튼과 라벨은 짧고 건조하게: "마치고 저장", "일시정지", "다시 시작"
- 감정이 오가는 순간(복귀, 저장 완료)에만 다정한 문장을 쓴다: "다시 왔네요. 4분 동안 자리를 비웠어요."
- "이탈이 감지되었습니다", "성공적으로", 느낌표를 쓰지 않는다.
- 이탈이 참고 기록이라는 설명은 화면마다 한 곳에만 둔다.
- 명세에 없는 수치(목표 시간, 지난주 대비 증감 등)를 만들어 넣지 않는다.
