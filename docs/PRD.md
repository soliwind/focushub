## 프로젝트 개요
---
### 한 줄 정의
탭 이탈 감지 기능을 갖춘 웹 기반 개인·스터디그룹 학습 타이머

### 제품 목표
사용자가 공부 시간을 쉽게 측정하고 학습 중 다른 탭으로 이탈하는 상황을 인지하여 집중력을 유지하도록 돕는다. 개인 학습 기록을 누적·조회할 수 있으며, 가입한 스터디그룹에 학습 시간이 자동으로 합산되어 구성원 간 지속적인 학습 습관 형성과 동기 부여를 지원한다.

### 배경
학생들은 공부를 시작하더라도 학습 시간을 정확히 기록하기 어렵고, 메신저·동영상·검색 등 다른 브라우저 탭으로 쉽게 이탈한다. 기존 타이머는 개인 시간 측정에 집중하거나 스터디그룹의 기록 공유 기능이 부족한 경우가 많다. 본 서비스는 데스크톱 웹 환경에서 사용할 수 있는 학습 타이머, 탭 이탈 감지, 개인 통계, 그룹 기록 집계를 결합한 MVP를 제공한다.

### 사용자 문제
혼자 공부할 때 학습을 시작하고 지속할 동기가 부족하며, 실제로 공부한 시간을 정확히 파악하기 어렵다. 또한 타이머를 켠 상태에서 다른 탭으로 이동해도 이를 인지하지 못해 측정된 시간과 실제 집중 시간이 달라질 수 있다. 스터디그룹 구성원은 자신의 학습 기록을 그룹에 공유하고 누적하는 과정도 번거롭다.

### 해결 방안
사용자가 학습 과목 또는 세션 정보를 입력한 뒤 타이머를 시작·일시정지·종료할 수 있도록 한다. 브라우저 탭이 비활성화되거나 다른 탭으로 이동하면 이탈 상태를 감지하고 사용자에게 알림을 제공한다. 종료된 세션은 개인 학습 기록과 통계에 저장되며, 사용자가 가입한 스터디그룹의 학습 시간에 자동으로 합산된다.

### 차별점
단순 시간 측정을 넘어 탭 이탈 감지로 집중 상태를 확인하고, 개인 기록과 스터디그룹 집계를 하나의 흐름으로 연결한다. 그룹 순위 경쟁만 강조하기보다 개인의 꾸준한 학습 습관 형성을 중심에 두며, 이탈 횟수·집중 시간·총 학습 시간 등 행동 기반 통계를 제공한다. 브라우저의 기술적 제약상 탭 내부의 실제 행동을 감시하지 않고 탭 활성 상태만 감지하여 개인정보 침해를 최소화한다.

### 타겟 사용자
데스크톱 웹 브라우저를 주로 사용하는 중·고등학생, 대학생, 취업 준비생 및 자격증 수험생이다. 혼자 공부할 때 집중력과 지속성이 부족하지만, 스터디그룹에 참여하면 일정한 학습 습관을 만들 수 있다고 느끼는 사용자다. 하루 또는 주 단위 학습 시간을 확인하고 싶어 하며, 다른 구성원과 학습 기록을 공유하는 데 동의한 사용자다. 부가적으로 스터디그룹을 생성하고 구성원 및 그룹 기록을 관리하는 운영자도 주요 사용자에 포함된다.

### 사용자 시나리오
사용자는 웹 서비스에 접속해 로그인한 뒤 개인 또는 가입한 스터디그룹을 선택한다. 과목이나 학습 목표를 입력하고 타이머를 시작한 후 공부한다. 다른 브라우저 탭으로 이동하면 서비스가 탭 이탈을 감지해 화면에 상태를 표시하고, 다시 돌아오면 이탈 횟수와 시간을 기록한다. 사용자가 타이머를 종료하면 실제 학습 세션이 저장되고 개인 통계에 반영된다. 동시에 해당 세션의 공개 설정에 따라 가입한 스터디그룹의 총 학습 시간에 자동 합산된다. 사용자는 일별·주별 학습 시간과 집중 상태를 확인하고 다음 학습 목표를 설정한다. 그룹 운영자는 그룹 구성원별 또는 전체 누적 학습 기록을 확인한다.

### 핵심 지표
핵심 지표는 주간 활성 사용자 수, 타이머 시작 후 세션 완료율, 사용자당 주간 학습 세션 수, 사용자당 주간 누적 학습 시간, 7일 및 30일 재방문율, 타이머 사용자의 주간 습관 유지율, 탭 이탈 감지 후 복귀율, 스터디그룹 가입률, 그룹 기록 자동 집계 성공률이다. MVP 초기 목표는 타이머 시작 세션의 60% 이상이 정상 종료되고, 가입 사용자의 30일 재방문율 25% 이상, 저장된 세션의 그룹 집계 성공률 99% 이상을 달성하는 것이다.

### 리스크
브라우저 탭 이탈 감지는 사용자가 다른 창이나 기기를 사용하는 상황까지 완전히 판단할 수 없으므로 실제 집중도를 정확히 측정하지 못할 수 있다. 과도한 이탈 알림은 사용자의 피로감이나 서비스 이탈을 유발할 수 있다. 그룹 간 학습 시간 비교는 경쟁 스트레스와 부정 기록 입력을 만들 수 있으며, 학습 기록 공개로 개인정보 문제가 발생할 수 있다. 브라우저 종료·네트워크 단절·기기 절전으로 세션 데이터가 유실될 위험이 있고, 타이머를 켜 둔 채 자리를 비우는 행위로 통계 신뢰도가 낮아질 수 있다. 이를 완화하기 위해 이탈 감지는 참고 지표로 안내하고, 알림 설정·기록 공개 범위·세션 자동 종료 기준을 제공하며, 서버 저장과 복구 처리를 적용해야 한다.
